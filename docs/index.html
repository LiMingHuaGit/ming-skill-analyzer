来自分析报告的能力目录

五条流水线，分析过的每条都有证据

以下能力描述直接取自 analysis.json，每条均追溯到 SKILL.md 的源文件行号。

单目标路由与范围控制
判断请求是否属于单个 Skill 的理解、教学或可视化，拒绝多 Skill 聚合、执行修改和普通代码审查。自指分析合法：description 明确允许「comparisons between that skill's own capabilities or execution branches」。
single-target-routing
确定性只读扫描
scan_skill.py 生成文件清单、脱敏文本、引用信号（带 confidence + detection_rule 字段，CSS/@media 和代码块内误报已过滤）及 schema v2 分析模板，不执行任何目标脚本。
deterministic-scan
证据化语义分析
以 facts.json 为事实权威，完成 analysis.json：capabilities / input_classes / lanes / nodes / edges / findings。每条结论必须有来源摘录，推断须明确标注。
evidence-analysis
严格质量验证
validate_analysis.py --strict 检查结构完整性、证据摘录真实性，输出三项质量指标：evidence_coverage（≥90% 才通过）、inference_ratio、unsupported_claims（必须为 0）。只接受 schema_version: 2。
strict-quality-validation
实时报告渲染与服务
render_report.py --live 生成三栏 HTML（文件树 + 解析报告 + 动态 SVG 流程图）；serve_report.py 在 127.0.0.1 提供文件 API，拒绝路径越界、符号链接和敏感文件。
live-report-delivery
工作原理

三步出报告，每步可单独重跑

每一步输入输出明确，永不覆盖既有运行目录（SKILL.md + scan_skill.py + render_report.py 三处一致强制）。

1
确定性扫描
读取 Skill 目录所有文件，脱敏、提取引用信号，生成 facts.json（事实层）和 analysis-template.json（schema v2 模板）。不执行目标代码。
python3 scripts/scan_skill.py ./my-skill --output-dir ./out --prompt "分析触发边界"
2
语义分析 + 严格验证
基于 facts.json 完成 analysis.json（capabilities / input_classes / lanes / nodes / edges），运行 --strict 验证确保零未支持声明、证据覆盖率 ≥ 90%。
python3 scripts/validate_analysis.py out/facts.json out/analysis.json --strict
3
渲染 + 实时服务
生成三栏 HTML，用 loopback 服务器提供实时文件预览 API，浏览器按需读取当前磁盘文件。URL 验证后交付。
python3 scripts/render_report.py out/facts.json out/analysis.json --output out/report.html --live python3 scripts/serve_report.py --report out/report.html --skill-root ./my-skill --open
来自自指分析的设计结论

工具对自身输出了这四条结论

以下内容直接来自 findings 数组，不是手写文案。

strength · high
永不覆盖策略在三处一致强制
「Never overwrite an existing analysis run」在 SKILL.md 声明；scan_skill.py 检测到已有文件时 exit(4)；render_report.py 检测到已有报告时 raise SystemExit。三层强制消除「批准覆盖」歧义。
strength · high
文档与实现现已全面对齐（v2 修复完成）
analysis-schema.md 和 analysis-guidance.md 均描述 v2 格式；validate_analysis.py 和 render_report.py 均只接受 v2；scan_skill.py 常量已清晰命名（FACTS_SCHEMA_VERSION / ANALYSIS_SCHEMA_VERSION）。经三轮修复后一致。
teaching-value · info
自指分析是检验 Skill 自我一致性的天然测试
本分析通过了自身的 --strict 验证（evidence_coverage 1.0，unsupported_claims 0），形成闭环——Skill 的质量标准对自身也成立。
boundary · low
服务器进程在 Agent 会话结束后被终止
SKILL.md 要求「不经用户要求不停止服务器」，但 Agent 会话结束时 serve_report.py 进程实际被终止。这是宿主能力边界而非 Skill 缺陷，Agent 应在交付时说明复现命令。
安装与运行

零外部依赖，Python 标准库即可

脚本只用 Python 3.10+ 标准库，无需 pip install。

快速开始

# 1. 克隆 git clone https://github.com/LiMingHuaGit/ming-skill-analyzer # 2. 扫描你的 Skill python3 scripts/scan_skill.py ./my-skill \ --output-dir ./my-analysis \ --prompt "分析触发场景" # 3. 完成 analysis.json 后验证并渲染 python3 scripts/validate_analysis.py my-analysis/facts.json my-analysis/analysis.json --strict python3 scripts/render_report.py my-analysis/facts.json my-analysis/analysis.json \ --output my-analysis/report.html --live # 4. 本地浏览（127.0.0.1 only） python3 scripts/serve_report.py \ --report my-analysis/report.html \ --skill-root ./my-skill --open
